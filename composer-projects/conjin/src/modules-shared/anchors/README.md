# anchors

This module allows you to set up a semantic anchor tree in a linear fashion.

## Usage

So let's say you have the following document structure:

```
Top level title
1. First section
2. Second section
2.1. Subsection
```

Then you can create anchor IDs for the sections below the page title like this:

```
- first-section
- second-section
  - subsection
```

The anchor tree is generated by calls to `anchor_create(level, id)`, where a heading level and an ID are passed. In the example, the level of "1. First section" is `2` and its ID is `first-section`. Each individual ID may contain hyphens, while `anchor_collect()` joins the IDs along the current tree path with underscores. The collected HTML ID for the subsection is therefore `second-section_subsection`. If the target is named `top-level`, its URL would typically end in `/top-level/#second-section_subsection`; the target ID is not part of the anchor ID.

## API

The functions below update or inspect the current path through a target's anchor tree.

### `anchor_create(int $level, string $id): array`

Creates an anchor at the given heading level, makes it the current anchor, and returns its path as an ordered list of IDs. Level `2` creates a root anchor. A higher level creates a child of the current path, while returning to a lower level removes the deeper components from the current path before creating the new anchor.

The level must be at least `2`, levels may not be skipped, and an ID may not be used more than once below the same parent. Violating one of these constraints causes an assertion failure.

```php
anchor_create(2, 'second-section');
$anchor_ids = anchor_create(3, 'subsection');
```

After these calls, `$anchor_ids` is `['second-section', 'subsection']`.

### `anchor_create_from_title(int $level, string $title): array`

Converts the title to a kebab-case ID with the core `kebabize()` helper and then calls `anchor_create()` with that ID. It returns the created anchor's path and has the same level and duplicate-ID constraints as `anchor_create()`.

```php
anchor_create_from_title(2, 'Second section');
$anchor_ids = anchor_create_from_title(3, 'Generated subsection');
```

After these calls, `$anchor_ids` is `['second-section', 'generated-subsection']`.

### `get_current_anchor_ids(): array`

Returns the current anchor path as an ordered list of IDs, from the root anchor to the current anchor.

```php
$anchor_ids = get_current_anchor_ids();
```

For the nested example above, `$anchor_ids` is `['second-section', 'generated-subsection']`.

### Related core helper: `anchor_collect($anchor_ids): string`

This helper is part of Conjin core rather than the `anchors` module. It joins an anchor path with underscores so it can be used as an HTML ID or URL fragment.

```php
$html_id = anchor_collect(get_current_anchor_ids());
// second-section_generated-subsection
```
